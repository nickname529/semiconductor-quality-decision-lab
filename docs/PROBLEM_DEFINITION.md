# 문제정의 — Draft

**질문:** 익명 반도체 공정 측정값으로 만든 위험 순위가 제한된 추가 검토 용량에서
FAIL 표본을 얼마나 포함하며, 얼마나 놓치고, 정상 표본을 얼마나 추가 확인하게 하는가?

## 1인 프로젝트 범위

Kim Jiseong이 단독 소유·검토하는 포트폴리오다. 협업자 확보, 현업 고객 인터뷰,
실제 fab 접근 없이 공개 데이터와 로컬 실행으로 끝낼 수 있는 분석 단위를 만든다.
AI 지원 구현·작성 내역은 AI_USAGE.md에 별도 공개한다.

입력은 UCI SECOM 익명 측정값과 PASS/FAIL 테스트 라벨이다. 출력은 위험 순위,
가정한 용량별 검토 후보와 FN/FP/TP/TN, 결과 보고서다. row_id는 원본의 0-based 행 번호다.
고객사 정보나 실제 웨이퍼 좌표는 원본에 없다. 원래 README의 wafer-map 분석은
현재 데이터로 수행할 수 없으므로 이번 범위에 포함하지 않는다.

## 완료 조건

- 출처·라이선스·원본 해시를 기록한다.
- 결측·상수·라벨·시간 분포를 실제 계산한다.
- 시간 분할 이후 전처리를 train에서만 학습한다.
- 분석 전에 고정한 모델·용량 정책으로 validation/test를 평가한다.
- 개별 예측과 의사결정을 저장해 결과를 재계산할 수 있게 한다.
- 실행법·검증·한계를 문서화한다. 사람의 최종 해석·공개 승인은 별도 상태다.

모델의 일정 성능 달성은 완료 조건이 아니다. 낮은 성능도 의사결정 근거로 기록한다.
정책 최적화·추가 모델 탐색·실시간 서비스·외부 LLM·배포는 현재 범위 밖이다.
