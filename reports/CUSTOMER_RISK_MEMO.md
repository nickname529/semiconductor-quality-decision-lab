# 고객 위험 시나리오 메모 — Draft

고객 데이터와 인터뷰, 불량 비용, 검사 정확도, 납기·매출 자료는 제공되지 않았다.
따라서 고객 손실·비용 절감·매출 효과를 추정하지 않는다.

| 분석에서 관찰할 것 | 가정 가능한 후속 위험 | 현재 증거의 한계 |
|---|---|---|
| FAIL 미검토(FN) | 추가 확인 기회를 놓칠 가능성 | 실제 유출·고객 불량과 동일하지 않음 |
| PASS 추가 검토(FP) | 검토 부담 증가 가능성 | 실제 시간·비용·납기 영향 불명 |
| threshold 후보 수 증가 | 가정 용량 초과 가능성 | 실제 검사 설비·인력 용량 없음 |
| 시간 구간별 성능 차이 | 향후 기간 일반화 위험 | 공정 변경·원인 정보 없음 |

추가 검토 후보 생성은 출하 승인·거절·폐기 명령이 아니다.
운영 적용 여부는 현장 데이터·비용·검사 정확도·검토자의 책임 범위가 있어야 판단할 수 있다.
이는 다음 단계에 필요한 정보 목록이며, 해당 단계 실행이나 승인을 뜻하지 않는다.
